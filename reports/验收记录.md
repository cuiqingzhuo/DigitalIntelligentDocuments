## Android 模拟器

在 Android 16（API 36）x86_64 模拟器安装调试包，经 A01-A 架标深链接启动查书，选择《数据结构》第 3 版，从相册导入自建样例。包内 OCR 读到「数据结构」「第3版」「TP311.12/03」，本机显示第 1 排、画面左起第 3 本。两次模拟器单帧推理约 3.2–3.5 秒。输入两个演示条码后，服务器保留首拿 H02 错误、最终 H09 正确的两条记录。普通安卓真机和现场三帧 P95 尚待测量。[安卓识别截图](screens/android-recognition.png) · [安卓核验截图](screens/android-verification.png)

模拟器启用飞行模式并关闭 Wi‑Fi 后，应用仍从缓存书目匹配到相同的候选，界面显示数据缓存时间和一项待同步记录。该帧本机识别约 3.0 秒，恢复联网后成功同步到服务器。

调试包通过 APK v2 签名校验，大小 178,760,806 字节。SHA‑256 为 `0e16bcb380742a02f27f21d41e098c077adb5f370f1517633a0f368e5554c5d1`。[安装包与校验信息](../release/README.md)

## 公开数据实验

### 题名完整索引召回

重排器只在 12,433 条中文训练三元组上拟合。ISBN 和电子书 ID 用于确定正确候选。每个分区都从该分区的完整目录建立索引。Gutenberg 单独评测。

| 分区 | 查询数 | 字符串基线 Top‑1 / Top‑3 | 训练重排 Top‑1 / Top‑3 |
|---|---:|---:|---:|
| 中文验证 | 1,572 | 1,572 / 1,572 | 1,570 / 1,572 |
| 中文测试 | 1,666 | 1,664 / 1,666 | 1,664 / 1,666 |
| Gutenberg 验证 | 1,500 | 1,496 / 1,500 | 1,490 / 1,498 |
| Gutenberg 测试 | 1,500 | 1,500 / 1,500 | 1,494 / 1,499 |

演示继续采用字符串基线。重排器在中文验证集的模拟文本上校准得到 0.76 最低分和 0.08 最小分差，命中 1,484/1,572 个正例，触发 17/1,483 个构造负例。现场发布使用本馆实拍重新校准。[题名实验数据](title-retrieval.json)

### 书脊检测和文字读取

YOLO11n OBB 使用 903 张训练图和 14,218 个训练四点框，完成 5 轮后按验证集选取检查点。按原划分在 301 张测试图、4,757 个测试实例上得到旋转框 **mAP50 98.59%**、**mAP50–95 80.98%**。输入分辨率为 640，RTX 4060 Laptop GPU 平均模型推理 18.03 毫秒每图，另有预处理和后处理。该计时只覆盖检测。训练器对导出的部分 JPEG 重编码，原 ZIP 和原始标注保留。[测试指标](vision-obb.json) · [训练记录](vision-obb-training.csv) · [检测权重](../models/bookspine-pilot.pt)

SpineText-40 的整图 RapidOCR 诊断产生 17,141 次编辑，参考文本共 20,577 字符，忽略空白后的字符错误率为 **83.30%**。书脊旋转、文字漏读与整图读序会影响这个诊断。正式试点应另测裁剪校正后的逐书脊字符错误率与找书命中率。[辅助 OCR 诊断](ocr-spinetext40.json)
